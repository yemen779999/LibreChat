## 2026-03-31 - Message Tree Construction Optimization
**Learning:** `buildTree` in `packages/data-provider/src/messages.ts` is a hot execution path called on every streaming SSE chunk and UI re-render. Using plain JS objects for string key lookups (`Record<string, ...>`) causes hidden class transitions/dictionary lookups in V8, while multi-pass depth assignment (`.some()` followed by `.filter()` and `for..of`) causes unnecessary array iterations and allocations. Replacing plain objects with `Map` and combining cycle back-edge pruning with depth assignment in a single-pass in-place loop reduced execution time by 36-40%.
**Action:** Prefer `Map` over plain object key lookups for dynamic string IDs in high-frequency data structures, and combine tree traversal passes with in-place array filtering when pruning cycles.
